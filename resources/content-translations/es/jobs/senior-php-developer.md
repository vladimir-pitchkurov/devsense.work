# Desarrollador PHP Senior (Laravel)

Buscamos un **Desarrollador PHP Senior** apasionado por el código limpio, las arquitecturas sólidas y los sistemas orientados al desarrollador. En este rol, ayudarás a diseñar e implementar nuestra plataforma principal, microservicios y APIs internas.

## Responsabilidades clave

- Diseñar, construir y mantener código PHP/Laravel eficiente, reutilizable y confiable.
- Coordinar con los desarrolladores frontend para integrar APIs.
- Optimizar estructuras de bases de datos (MySQL/PostgreSQL) e implementar mecanismos de caché (Redis).
- Configurar pipelines de pruebas automatizadas y revisar cambios de código.

## Requisitos

- Más de 5 años de experiencia profesional en desarrollo backend con PHP.
- Profundo conocimiento del funcionamiento interno del framework **Laravel 10/11/13**.
- Experiencia demostrada con Docker (incluyendo Laravel Sail), poolers de conexiones y diseño de microservicios.
- Familiaridad con herramientas de CI/CD y desarrollo guiado por pruebas (TDD).
