# Développeur PHP Senior (Laravel)

Nous recherchons un **Développeur PHP Senior** passionné par le code propre, les architectures solides et les systèmes orientés développeurs. À ce poste, vous contribuerez à la conception et à l'implémentation de notre plateforme principale, de nos microservices et de nos API internes.

## Responsabilités principales

- Concevoir, développer et maintenir un code PHP/Laravel efficace, réutilisable et fiable.
- Collaborer avec les développeurs frontend pour intégrer les API.
- Optimiser les structures de bases de données (MySQL/PostgreSQL) et implémenter des mécanismes de cache (Redis).
- Mettre en place des pipelines de tests automatisés et effectuer des revues de code.

## Prérequis

- Plus de 5 ans d'expérience professionnelle en développement backend PHP.
- Expertise approfondie du fonctionnement interne du framework **Laravel 10/11/13**.
- Expérience avérée avec Docker (y compris Laravel Sail), les gestionnaires de connexions (connection poolers) et l'architecture de microservices.
- Bonne connaissance des outils CI/CD et du développement piloté par les tests (TDD).
