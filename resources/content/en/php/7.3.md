# PHP 7.3: Major Features

Have you ever spent hours debugging a silent JSON parsing failure on production because you forgot to check `json_last_error()`? PHP 7.3 addresses this Developer Experience (DX) pain point by introducing `JsonException` via the `JSON_THROW_ON_ERROR` flag. It represents a major safety and convenience release, polishing syntax ergonomics like indented heredocs, trailing commas in calls, and adding essential standard library helpers.

<a id="flexible-heredoc"></a>
## Flexible Heredoc and Nowdoc

The closing label is **no longer required** to sit at column 0 in the old rigid form: it may be **indented**, and the same indentation is **stripped from every line** in the body. That makes embedded SQL, HTML, and CLI help text far more readable in PSR-12–friendly code.

**Migration caveat:** if the body **contains the same token** as the closing label (now possibly indented), PHP may treat it as **ending the string early**—pick **unique, long labels** (`SQL_GET_USER` rather than `SQL`).

```php
// src/QueryBuilder.php
$query = <<<SQL
    SELECT id, name
    FROM users
    WHERE active = 1
    SQL;
```

> [!NOTE]
> Did you know? The indentation of the closing label dictates the indentation stripped from the text. If you indent the body *less* than the closing label, PHP will throw a ParseError.

<a id="trailing-commas-calls"></a>
## Trailing commas in function and method calls

Calls may end with a trailing comma—handy for multi-line diffs and generated argument lists:

```php
// src/LoggerService.php
$this->logger->info(
    'User saved',
    [
        'id' => $user->id,
        'ip' => $request->ip(),
    ],
);
```

This applies to **calls**, not to declaring `function foo($a,)` parameters in 7.3 (parameter list trailing commas arrived on a different schedule in PHP 8.0).

> [!NOTE]
> Did you know? Trailing commas in function *declarations* (defining parameters) are still a syntax error in PHP 7.3. They are only supported in *invocations* (calls).

<a id="list-references"></a>
## Reference assignments in `list()` and `[]`

Destructuring can bind **by reference**:

```php
// src/Destructure.php
[&$head, $middle, &$tail] = $parts;
// same idea with list():
list(&$a, $b) = $pair;
```

Use this when you intentionally mutate pieces of a shared structure; otherwise prefer values to keep data flow obvious.

<a id="instanceof-literals"></a>
## `instanceof` with literals

The left-hand side may be a **literal**; the result is always **`false`**. This exists mainly for **consistency** and static-analysis friendliness, not for runtime logic you would rely on.

```php
// src/Validation.php
$result = (123 instanceof User); // false
```

<a id="compile-error"></a>
## `CompileError`

`CompileError` is introduced as a base for certain **compile-time failures**; `ParseError` **extends** it. Initially this shows up most visibly when **`token_get_all($code, TOKEN_PARSE)`** hits parse issues—some situations that were fatals may now surface as exceptions in tooling.

```php
// src/ErrorHandling.php
try {
    eval('invalid code');
} catch (CompileError $e) {
    echo "Compilation failed: " . $e->getMessage();
}
```

<a id="core-helpers"></a>
## New and updated core helpers

* **`array_key_first($array)`** / **`array_key_last($array)`** — avoid `reset()`/`end()` key hacks; behavior is defined for your array type (see manual for empty arrays).
* **`is_countable($value)`** — `true` for arrays and objects implementing `Countable`—replaces the common `is_array($x) || $x instanceof \Countable` guard before `count()`.
* **`hrtime($as_number = false)`** — monotonic high-resolution time (nanoseconds); prefer over `microtime(true)` for **intervals** (not wall-clock calendar time).
* **`net_get_interfaces()`** — enumerates network interfaces where supported (platform-dependent).

```php
// src/Helpers.php
$firstKey = array_key_first($myArray);
if (is_countable($data)) {
    $count = count($data);
}
```

> [!NOTE]
> Did you know? `hrtime()` utilizes the system's monotonic clock, which is immune to system time changes (like NTP syncs). This makes it the only reliable way to measure execution time intervals.

<a id="json-exceptions"></a>
## JSON: `JSON_THROW_ON_ERROR` and `JsonException`

Pass **`JSON_THROW_ON_ERROR`** to **`json_encode()`** / **`json_decode()`** to get a **`JsonException`** instead of juggling **`json_last_error()`**. **`JSON_PARTIAL_OUTPUT_ON_ERROR`** still wins when both flags apply.

```php
// src/JsonParser.php
try {
    $data = json_decode($json, true, 512, JSON_THROW_ON_ERROR);
} catch (JsonException $e) {
    // Handle error
}
```

<a id="argon2id"></a>
## Password hashing: Argon2id

When PHP is built with a sufficiently new **libargon2**, **`password_hash()`** accepts **`PASSWORD_ARGON2ID`**, giving you Argon2’s **i+d hybrid** variant alongside existing Argon2i support.

```php
// src/Security.php
$hash = password_hash('secret', PASSWORD_ARGON2ID);
```

<a id="extensions-stdlib"></a>
## Notable extensions & stdlib

* **PCRE**: engine upgraded to **PCRE2**—subtle behavior changes (stricter character-class ranges, etc.); **`preg_quote()`** also escapes **`#`**.
* **Multibyte (mbstring)**: **Unicode 11**, **>2GB strings**, faster case operations; **full case-folding** for case-insensitive comparisons; **`mb_ereg_*` named captures** aligned closer with PCRE ergonomics.
* **LDAP**: LDAP **controls** plumbed through search/modify APIs and **`ldap_parse_result()`**; option handling for server/client controls improved.
* **MySQLi / PDO MySQL**: prepared statements can surface **fractional seconds** for `DATETIME(6)` / `TIMESTAMP(6)` style columns.
* **FPM**: logging knobs (`log_limit`, `log_buffering`, `decorate_workers_output`); **`getallheaders()`** available under FPM.
* **Sessions / cookies**: **`session_set_cookie_params(array $options)`** and **`session.cookie_samesite`**; **`setcookie()` / `setrawcookie()`** array `$options` including **`samesite`**.
* **Stream**: IPv6 names from **`stream_socket_get_name()`** use **bracketed** host form (e.g. `[::1]:1337`).
* **SPL autoload**: if an autoloader **throws**, **later autoloaders are skipped**.
* **IMAP**: **rsh/ssh** logins **disabled by default**—enable only with care (`imap.enable_insecure_rsh`).

## Practical recipes

```php
// src/recipes.php
if (is_countable($rows)) {
    $n = count($rows);
}
```

### Stable first/last keys

```php
// src/recipes.php
$firstKey = array_key_first($map);
$lastKey = array_key_last($map);
```

### Strict JSON parsing

```php
// src/recipes.php
try {
    $payload = json_decode($raw, true, 512, JSON_THROW_ON_ERROR);

    // handle or wrap
}
```

### High-resolution timing

```php

```

<a id="common-mistakes"></a>
## Common Mistakes

Here are some typical mistakes made by developers in PHP 7.3:

### 1. Indenting Heredoc Closing Labels Unintentionally
If the body has lines indented *less* than the closing label, or the closing label has trailing spaces, a ParseError is thrown.
```php
// src/BadHeredoc.php
// Bad: Body is indented less than the closing tag, throwing ParseError
$text = <<<TEXT
Line 1
    Line 2
      TEXT;
```
```php
// src/GoodHeredoc.php
// Good: The closing tag indentation matches the minimum indent of the body
$text = <<<TEXT
    Line 1
    Line 2
    TEXT;
```

### 2. Using `continue` inside `switch`
`continue` inside switch statements acts like `break` in PHP, which often results in infinite loops when developers expect it to proceed to the next loop iteration. PHP 7.3 emits a warning for this.
```php
// src/BadContinueSwitch.php
// Bad: Emits warning: "continue" targeting "switch" is equivalent to "break"
foreach ($items as $item) {
    switch ($item) {
        case 'skip':
            continue;
    }
}
```
```php
// src/GoodContinueSwitch.php
// Good: Use "continue 2" to target the outer foreach loop
foreach ($items as $item) {
    switch ($item) {
        case 'skip':
            continue 2;
    }
}
```

<a id="limitations"></a>
## Limitations

* **Trailing Commas**: Only supported in function and method calls. Trying to write `function foo($a, $b,) {}` (trailing comma in declaration) will throw a syntax ParseError.
* **Flexible Heredoc**: The closing label must be on its own line and cannot have any text (except a semicolon or newline) after it. Any trailing whitespace after the closing identifier will trigger a compiler error.

<a id="backward-incompatible"></a>
## Backward incompatible changes (migration notes)

### Core

* **Flexible heredoc/nowdoc**: strings that **embed the closing label** can change meaning or become **parse errors**—rename labels or escape content.
* **`continue` inside `switch`**: now emits a **warning** (in PHP it behaved like `break`). **Audit `switch` + `continue`.**
* **`ArrayAccess` with numeric string keys**: for literal **`"123"`** keys, PHP **stops coercing** to integer for `ArrayAccess`—**`offsetGet("123")`** is called instead of **`offsetGet(123)`**.
* **Static properties via reference tricks**: you can no longer **split** inherited static properties using reference assignment.
* **References from array/property accesses**: references returned from chained **array/property** reads are **unwrapped immediately**.
* **Unpacking `...$traversable`**: **non-integer keys** on `Traversable` **no longer unpack** for calls.
* **Warnings promoted to exceptions (`EH_THROW`)**: such exceptions **no longer populate** **`error_get_last()`**.
* **`TypeError` messages**: wrong types display as **`int` / `bool`**, not **`integer` / `boolean`**.
* **`compact()`**: **undefined variables** passed by name produce a **notice**.
* **`getimagesize()`** (and friends): BMP MIME reported as **`image/bmp`** (IANA), not **`image/x-ms-bmp`**.
* **Cookies (from PHP 7.3.23)**: incoming cookie **names** are **not URL-decoded** (security alignment).

### BCMath

* Warnings route through PHP’s **standard error handler**.
* **`bcmul()` / `bcpow()`** honor the **requested scale** more strictly.

### IMAP

* **rsh/ssh** tunneling **off** unless you explicitly enable **`imap.enable_insecure_rsh`**.

### Multibyte regex (`mb_ereg_*`)

* **Named captures** change **match array shape** and **`mb_ereg_replace()`** substitution syntax.

### MySQLi and PDO MySQL

* **Fractional seconds** now visible in bound result paths.

### Reflection

* String exports use **`int` / `bool`** type spellings in output.

### SimpleXML

* Numeric operations on SimpleXML text nodes choose **int vs float** instead of always coercing through **int**.

### Miscellaneous platform

* **BeOS** support removed; **`ext_skel`** redesigned.
* **`stream_socket_get_name()`** IPv6 formatting uses **brackets**.

<a id="deprecations"></a>
## Deprecations (fix early)

High-signal core items:

* **Case-insensitive `define()`** (`true` as third argument) and using a **different case** than the definition.
* **Namespaced function named `assert()`**—avoid; the engine treats **`assert()`** specially.
* **Non-string needles** in **`strpos` family**—cast explicitly.
* **`fgetss()`**, **`gzgetss()`**, **`SplFileObject::fgetss()`**, and **`string.strip_tags` filter**.
* **`FILTER_FLAG_SCHEME_REQUIRED` / `FILTER_FLAG_HOST_REQUIRED`** with **`FILTER_VALIDATE_URL`** (redundant).
* **`image2wbmp()`** (GD).
* **`Normalizer::NONE`** with ICU ≥ 56.
* Undocumented **`mbereg_*()` aliases**—switch to **`mb_ereg_*()`**.
* Deprecation of **`pdo_odbc.db2_instance_name`** INI.

<a id="other-changes"></a>
## Other changes & operations (build, INI, perf)

* **Syslog INI**: **`syslog.facility`**, **`syslog.filter`**, **`syslog.ident`** when **`error_log=syslog`**.
* **GC**: cyclic garbage collection improvements.
* **`var_export()`** on **`stdClass`** uses **`(object) array (...)`** style output.
* **FTP** defaults to **binary** transfers.
* **FILTER_VALIDATE_FLOAT** accepts a **`thousand`** option for allowed separators.
* **OpenSSL** streams: **`min_proto_version` / `max_proto_version`**.
* **PDO SQLite**: open **read-only** databases via **`PDO::SQLITE_ATTR_OPEN_FLAGS`** + **`PDO::SQLITE_OPEN_READONLY`**.
* **XML**: external entity ref handler **return value** respected.
* **cURL**: requires **libcurl ≥ 7.15.5**.
* **OPcache**: stale **`opcache.inherited_hack`** directive removed.
* **ODBC**: **Birdstep / ODBCRouter** support removed.

<a id="closing-thoughts"></a>
## Closing thoughts

PHP 7.3 rewards a **focused diff review**: grep for **`continue` + `switch`**, **`compact(`**, **`ArrayAccess`** implementations, **heredoc** labels, and **`...$generator` argument unpacking**. Re-run **regex** and **date/time** integration tests, then roll forward—**7.4** will add far larger language features, so clearing 7.3 deprecations early reduces noise on the next jump.
