# PHP 7.3: Главные нововведения

Случалось ли вам часами отлаживать упавший на проде импорт данных просто потому, что вы забыли проверить `json_last_error()` после парсинга JSON? PHP 7.3 решает эту вечную боль разработчиков, внедряя `JsonException` с помощью флага `JSON_THROW_ON_ERROR`. Данный релиз значительно повышает удобство разработки (DX), предлагая долгожданные отступы в heredoc-строках, висячие запятые в аргументах вызова функций и ряд полезных встроенных хелперов.

<a id="flexible-heredoc"></a>
## Гибкий Heredoc и Nowdoc

Закрывающий маркер **больше не обязан** находиться в самом начале строки (на нулевой колонке). Теперь его можно **сдвинуть вправо (сделать отступ)**, и этот же отступ будет **автоматически вычтен из каждой строки** внутри тела heredoc. Это делает встроенный SQL, HTML или текст помощи в CLI-командах чистым и аккуратным в коде по PSR-12.

**Риск миграции:** если тело строки содержит тот же токен, который используется как закрывающий маркер (пусть даже с отступом), PHP может решить, что строка завершилась раньше времени. Используйте **уникальные длинные маркеры** (например, `SQL_GET_USER` вместо обычного `SQL`).

```php
// src/QueryBuilder.php
$query = <<<SQL
    SELECT id, name
    FROM users
    WHERE active = 1
    SQL;
```

> [!NOTE]
> А вы знали? Отступ закрывающего маркера задает эталон для удаления пробелов из текста. Если хотя бы одна строка в теле heredoc будет иметь меньший отступ, чем закрывающий маркер, PHP выдаст ошибку ParseError.

<a id="trailing-commas-calls"></a>
## Висячие запятые в вызовах функций

В вызовах функций и методов теперь разрешено оставлять висячую запятую в конце списка аргументов. Это делает diff в коммитах более чистым и удобным при генерации списков аргументов:

```php
// src/LoggerService.php
$this->logger->info(
    'User saved',
    [
        'id' => $user->id,
        'ip' => $request->ip(),
    ],
);
```

Это касается только **вызова** функций. Объявление сигнатуры вида `function foo($a,)` в PHP 7.3 по-прежнему запрещено (висячие запятые в параметрах объявлений появятся только в PHP 8.0).

> [!NOTE]
> А вы знали? Висячие запятые при объявлении функций в PHP 7.3 вызовут синтаксическую ошибку ParseError. Они разрешены исключительно при непосредственном запуске (вызове) функций.

<a id="list-references"></a>
## Деструктуризация по ссылке в `list()` и `[]`

При распаковке массивов теперь можно биндить переменные **по ссылке**:

```php
// src/Destructure.php
[&$head, $middle, &$tail] = $parts;
// И аналогично с list():
list(&$a, $b) = $pair;
```

Используйте это только при явной необходимости изменять части общего массива; в остальных случаях лучше работать по значению.

<a id="instanceof-literals"></a>
## `instanceof` с литералами

Левая часть выражения `instanceof` может быть **литералом**, в этом случае выражение всегда возвращает **`false`**. Это добавлено для консистентности парсера и удобства статического анализа, а не для применения в логике рантайма.

```php
// src/Validation.php
$result = (123 instanceof User); // false
```

<a id="compile-error"></a>
## `CompileError`

Класс `CompileError` добавлен как базовое исключение для ошибок компиляции; `ParseError` теперь **наследуется** от него. Чаще всего это заметно, когда **`token_get_all($code, TOKEN_PARSE)`** спотыкается на разборе кода — ошибки, которые раньше приводили к фатальному сбою, теперь могут перехватываться инструментами анализа кода.

```php
// src/ErrorHandling.php
try {
    eval('invalid code');
} catch (CompileError $e) {
    echo "Ошибка компиляции: " . $e->getMessage();
}
```

<a id="core-helpers"></a>
## Новые хелперы ядра

* **`array_key_first($array)`** / **`array_key_last($array)`** — избавляют от костылей с `reset()`/`end()` для получения ключей.
* **`is_countable($value)`** — возвращает `true` для массивов и объектов, реализующих `Countable` (замена конструкции `is_array($x) || $x instanceof \Countable`).
* **`hrtime($as_number = false)`** — монотонное системное время высокого разрешения (в наносекундах). Идеально для измерения интервалов выполнения кода, так как оно не подвержено прыжкам часов (в отличие от `microtime`).
* **`net_get_interfaces()`** — выдает список сетевых интерфейсов сервера (зависит от платформы).

```php
// src/Helpers.php
$firstKey = array_key_first($myArray);
if (is_countable($data)) {
    $count = count($data);
}
```

> [!NOTE]
> А вы знали? Функция `hrtime()` использует монотонные часы операционной системы, которые защищены от корректировок времени (например, по протоколу NTP). Это единственный надежный способ измерять микро-интервалы выполнения кода.

<a id="json-exceptions"></a>
## JSON: `JSON_THROW_ON_ERROR` и `JsonException`

Передавайте флаг **`JSON_THROW_ON_ERROR`** в функции **`json_encode()`** и **`json_decode()`**, чтобы ловить исключение **`JsonException`** вместо утомительных ручных проверок `json_last_error()`.

```php
// src/JsonParser.php
try {
    $data = json_decode($json, true, 512, JSON_THROW_ON_ERROR);
} catch (JsonException $e) {
    // Обработка ошибки
}
```

<a id="argon2id"></a>
## Хеширование паролей: Argon2id

Если PHP собран с актуальной библиотекой **libargon2**, функция **`password_hash()`** принимает алгоритм **`PASSWORD_ARGON2ID`**, который является гибридной (i+d) версией Argon2.

```php
// src/Security.php
$hash = password_hash('secret', PASSWORD_ARGON2ID);
```

<a id="extensions-stdlib"></a>
## Расширения и стандартная библиотека

* **PCRE**: движок обновлён до **PCRE2** — возможны тонкие изменения в поведении регулярных выражений (более строгие диапазоны в символьных классах); **`preg_quote()`** теперь экранирует символ **`#`**.
* **Multibyte (mbstring)**: поддержка **Unicode 11**, работа со строками **>2 ГБ**, ускоренные регистровые операции; именованные захваты в **`mb_ereg_*`** приведены к эргономике PCRE.
* **LDAP**: поддержка LDAP **controls** в функциях поиска и модификации, а также в **`ldap_parse_result()`**.
* **MySQLi / PDO MySQL**: подготовленные выражения теперь корректно отдают **дробную часть секунд** для полей типов `DATETIME(6)` / `TIMESTAMP(6)`.
* **FPM**: новые настройки логирования (`log_limit`, `log_buffering`, `decorate_workers_output`); функция **`getallheaders()`** теперь доступна внутри FPM.
* **Сессии и куки**: новые параметры для **`session_set_cookie_params()`** и куки-опция **`samesite`** в `setcookie()`.
* **Стримы**: адреса IPv6, возвращаемые из **`stream_socket_get_name()`**, теперь обёрнуты в квадратные скобки (например, `[::1]:1337`).
* **SPL autoload**: если один автозагрузчик **выбрасывает исключение**, последующие загрузчики в стеке **игнорируются** (раньше они вызывались цепочкой).
* **IMAP**: авторизация по протоколам **rsh/ssh отключена по умолчанию** из соображений безопасности (`imap.enable_insecure_rsh`).

<a id="common-mistakes"></a>
## Частые ошибки

Ниже описаны типичные ошибки разработчиков при переходе на PHP 7.3:

### 1. Неправильный отступ в Heredoc закрывающем маркере
Если хотя бы одна строка тела сдвинута левее, чем закрывающий маркер, или после маркера остались пробелы — PHP выдаст ошибку парсинга.
```php
// src/BadHeredoc.php
// Плохо: строки внутри тела сдвинуты левее маркера TEXT, вызовет ParseError
$text = <<<TEXT
Line 1
    Line 2
      TEXT;
```
```php
// src/GoodHeredoc.php
// Хорошо: отступ закрывающего маркера соответствует минимальному отступу строк тела
$text = <<<TEXT
    Line 1
    Line 2
    TEXT;
```

### 2. Использование `continue` в конструкции `switch`
В PHP оператор `continue` внутри switch ведет себя так же, как `break`. Разработчики часто ошибаются, ожидая, что он перейдет к следующему шагу внешнего цикла. В PHP 7.3 это вызывает предупреждение.
```php
// src/BadContinueSwitch.php
// Плохо: вызовет предупреждение "continue" в switch приравнивается к "break"
foreach ($items as $item) {
    switch ($item) {
        case 'skip':
            continue;
    }
}
```
```php
// src/GoodContinueSwitch.php
// Хорошо: используйте "continue 2" для перехода на следующую итерацию внешнего цикла foreach
foreach ($items as $item) {
    switch ($item) {
        case 'skip':
            continue 2;
    }
}
```

<a id="limitations"></a>
## Ограничения

* **Висячие запятые**: Поддерживаются исключительно в вызовах (аргументах функций/методов). Написание вида `function test($a, $b,) {}` выбросит синтаксическую ошибку ParseError.
* **Гибкий Heredoc**: Закрывающая строка должна содержать только маркер и точку с запятой (или перевод строки). Любые пробельные символы после маркера сломают парсер.

<a id="backward-incompatible"></a>
## Обратно несовместимые изменения (миграционные заметки)

### Ядро

* **Гибкий heredoc/nowdoc**: строки, в которых **содержится закрывающий маркер** (даже с отступом), могут изменить поведение или вызвать **ParseError**.
* **`continue` внутри `switch`**: теперь вызывает **warning**. **Проверьте все конструкции `switch` с `continue`.**
* **`ArrayAccess` с числовыми строковыми ключами**: для ключей вроде **`"123"`** PHP **больше не приводит** их к целому числу при обращении к объектам с `ArrayAccess` — вызывается **`offsetGet("123")`** вместо **`offsetGet(123)`**.
* **Статические свойства и ссылки**: статические свойства классов, унаследованные от родителя, больше нельзя разделять с помощью ссылок.
* **Ссылки из обращений к массивам/свойствам**: ссылки, возвращаемые из цепочек чтений массивов или свойств, разворачиваются немедленно.
* **Распаковка `...$traversable`**: **нецелочисленные ключи** у `Traversable` объектов больше **не распаковываются** при вызове функций.
* **Warnings повышены до исключений (`EH_THROW`)**: такие исключения больше не пишутся в **`error_get_last()`**.
* **Текст `TypeError`**: вместо **`integer` / `boolean`** теперь выводится **`int` / `bool`**.
* **`compact()`**: обращение к несуществующей переменной внутри `compact()` вызовет **notice**.
* **`getimagesize()`**: MIME-тип для BMP теперь отдается как **`image/bmp`** (вместо устаревшего `image/x-ms-bmp`).
* **Cookies (с PHP 7.3.23)**: имена входящих cookie-файлов **не** декодируются из URL-формата (безопасность).

### BCMath

* Предупреждения теперь идут через стандартный обработчик ошибок PHP.
* **`bcmul()` / `bcpow()`** более строго соблюдают указанный масштаб (scale).

### IMAP

* Туннелирование **rsh/ssh** отключено. Если нужно включить — используйте **`imap.enable_insecure_rsh`**.

### Регулярные выражения Multibyte (`mb_ereg_*`)

* Именованные карманы (captures) меняют структуру результирующего массива.

### MySQLi и PDO MySQL

* Дробная часть секунд теперь видна в результатах запросов для таймстампов.

### Reflection

* Экспорт типов в строку использует названия **`int` / `bool`**.

### SimpleXML

* Математические операции над текстовыми узлами SimpleXML теперь автоматически приводят значения к int или float вместо принудительного int.

### Платформа

* Прекращена поддержка операционной системы BeOS.
* **`stream_socket_get_name()`** форматирует адреса IPv6 с использованием квадратных скобок.

<a id="deprecations"></a>
## Deprecated (исправить заранее)

Главное:

* **Регистронезависимые константы**: передача `true` третьим аргументом в функцию `define()`.
* **Функция с именем `assert()` внутри пространства имен** — избегайте; движок обрабатывает `assert()` на системном уровне.
* **Не-строковые иглы** в функциях поиска подстроки (`strpos` и др.) — приводите аргумент к строке явно или используйте `chr()`.
* Функции **`fgetss()`**, **`gzgetss()`**, **`SplFileObject::fgetss()`** и стрим-фильтр **`string.strip_tags`**.
* Флаги **`FILTER_FLAG_SCHEME_REQUIRED` / `FILTER_FLAG_HOST_REQUIRED`** при валидации URL (теперь они включены по умолчанию).
* Функция **`image2wbmp()`** (GD).
* Константа **`Normalizer::NONE`** при ICU ≥ 56.
* Устаревшие алиасы **`mbereg_*()`** — перепишите на **`mb_ereg_*()`**.

<a id="other-changes"></a>
## Прочие изменения и эксплуатация (сборка, INI, perf)

* **Логирование Syslog**: настройки **`syslog.facility`**, **`syslog.filter`**, **`syslog.ident`** при перенаправлении `error_log=syslog`.
* **Сборщик мусора (GC)**: оптимизирована чистка циклических ссылок.
* **`var_export()`**: при экспорте объектов класса **`stdClass`** генерируется код вида **`(object) array(...)`** вместо устаревшего `__setState`.
* **FTP**: по умолчанию используется двоичный режим передачи файлов (binary).
* **FILTER_VALIDATE_FLOAT**: добавлена опция **`thousand`** для кастомных разделителей тысяч.
* **PDO SQLite**: добавлена возможность открывать базу данных в режиме «только для чтения» (`PDO::SQLITE_OPEN_READONLY`).
* **cURL**: теперь требуется библиотека **libcurl версии 7.15.5 или выше**.
* **OPcache**: удалена устаревшая директива `opcache.inherited_hack`.

## Интерактивный квиз

Проверьте свои знания о PHP 7.3:

1. **Какое утверждение о висячих запятых в PHP 7.3 верно?**
   * А) Они разрешены при вызове функций, но запрещены при их объявлении.
   * Б) Они разрешены при объявлении функций, но запрещены при их вызове.
   * В) Они разрешены и при объявлении, и при вызове.
   * Г) Они по-прежнему вызывают синтаксическую ошибку везде.

   <details>
   <summary>Показать ответ</summary>
   
   **Правильный ответ: А**  
   PHP 7.3 позволяет ставить запятую после последнего аргумента при вызове функции. Однако в списке параметров при объявлении функции висячая запятая приведет к ошибке ParseError.
   </details>

2. **Как поведет себя PHP 7.3 при обнаружении `continue` внутри блока `switch`?**
   * А) Молча перейдет к следующей итерации внешнего цикла.
   * Б) Вызовет фатальную ошибку компиляции.
   * В) Выдаст предупреждение (Warning) о том, что `continue` в `switch` работает как `break`.
   * Г) Выдаст предупреждение Deprecated.

   <details>
   <summary>Показать ответ</summary>
   
   **Правильный ответ: В**  
   PHP 7.3 выдает Warning, поскольку разработчики часто путают логику и ожидают продолжения внешнего цикла, тогда как в PHP `continue` внутри switch эквивалентен `break`.
   </details>

3. **Какая функция была добавлена в PHP 7.3 для проверки возможности подсчета элементов переменной перед запуском `count()`?**
   * А) `is_iterable()`
   * Б) `is_countable()`
   * В) `can_count()`
   * Г) `is_array_or_countable()`

   <details>
   <summary>Показать ответ</summary>
   
   **Правильный ответ: Б**

## Итог

Переход на PHP 7.3 требует **внимательного анализа диффа**: найдите в коде конструкции **`continue` + `switch`**, использование **`compact(`**, реализации **`ArrayAccess`**, маркеры **heredoc** и распаковку параметров **`...$generator`**. Запустите тесты для регулярных выражений и дат, после чего можно двигаться дальше — версия **7.4** принесет куда более масштабные изменения.
