# Senior PHP Разработчик (Laravel)

Мы ищем **Senior PHP разработчика**, увлеченного чистым кодом, надежной архитектурой и экосистемами, удобными для разработчиков. В этой роли вы будете помогать проектировать и внедрять нашу основную платформу, микросервисы и внутренние API.

## // app/Models/User.php
```php
namespace App\Models;

use Illuminate\Database\Eloquent\Factories\HasFactory;
use Illuminate\Foundation\Auth\User as Authenticatable;

class User extends Authenticatable
{
    use HasFactory;

    protected $fillable = [
        'name',

    ];
```

## Ключевые обязанности

- Проектирование, создание и поддержка эффективного, переиспользуемого кода на PHP/Laravel.
- Координация с фронтенд-разработчиками для интеграции API.
- Оптимизация структур баз данных (MySQL/PostgreSQL) и внедрение механизмов кэширования (Redis).
- Настройка конвейеров автоматического тестирования и проведение код-ревью.

## Требования

- 5+ лет опыта профессиональной бэкенд-разработки на PHP.
- Глубокие знания внутренних механизмов фреймворка **Laravel 10/11/13**.
- Практический опыт работы с Docker (включая Laravel Sail), пулерами соединений и архитектурой микросервисов.
- Знакомство с инструментами CI/CD и разработкой через тестирование (TDD).

## Условия работы

- 100% удаленный формат работы.
- Конкурентная заработная плата в GBP.
- 28 дней оплачиваемого ежегодного отпуска.
- Бюджет на обучение и профессиональный рост.
