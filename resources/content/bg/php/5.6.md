# PHP 5.6: Мост към модерния PHP

Един прост математически израз като `2 ** 3 ** 2` или строга проверка на изпратен от потребителя JSON могат напълно да променят логиката на изпълнение на вашата програма при преминаване към PHP 5.6. Като последна версия на клона 5.x, PHP 5.6 служи като мост между старото ядро на PHP и съвременната екосистема на PHP 7.

Преди PHP 5.6 писането на функции с динамичен брой аргументи изискваше използването на тромави конструкции като `func_get_args()` и тяхното предаване чрез бавното извикване `call_user_func_array()`. Импортирането на функции от пространства от имена изискваше създаването на излишни обвивки, а константите не можеха да съдържат дори базови математически формули.

> [!IMPORTANT]
> PHP 5.6 въведе вариадични сигнатури, разопаковане на аргументи и строги настройки за криптиране по подразбиране, за да подготви проектите за прехода към PHP 7.

<a id="variadic"></a>
## Вариадични параметри (`...$params`)

Функциите вече могат да приемат произволен брой аргументи без да разчитат на `func_get_args()`.

```php
// app/Helpers/Math.php
function sum(int $first, int ...$others): int
{
    $accumulator = $first;
    foreach ($others as $number) {
        $accumulator += $number;
    }
    return $accumulator;
}

echo sum(1, 2, 3, 4); // 10
```

* **Защо това е важно**: Сигнатурите на методите стават самодокументиращи се, а средите за разработка (IDE) могат коректно да проверяват типовете и да автодопълват аргументите.

<a id="unpacking"></a>
## Разопаковане на аргументи

Масиви и обекти `Traversable` могат да бъдат „разопаковани“ в списък с параметри директно при извикване на функция.

```php
// app/Services/Logger.php
$args = ["Потребителят %s влезе от IP %s", "admin", "127.0.0.1"];
echo sprintf(...$args);
```

* **Защо това е важно**: Заменя бавните и сложни извиквания на `call_user_func_array()` с чист нативен синтаксис, изпълняващ се на ниво компилатор.

<a id="pow-op"></a>
## Оператор за степенуване (`**`)

В PHP 5.6 е добавен операторът `**` за степенуване, който предлага по-кратка алтернатива на функцията `pow()`.

```php
// app/Services/Physics.php
$square = 4 ** 2; // 16
$cube = 2 ** 3;   // 8
```

> [!WARNING]
> Операторът `**` е дясно асоциативен. Това означава, че `2 ** 3 ** 2` се изчислява като `2 ** (3 ** 2) = 2 ** 9 = 512`, а не като `(2 ** 3) ** 2 = 8 ** 2 = 64`.

<a id="use-imports"></a>
## `use function` и `use const`

Конструкцията `use` е разширена и вече позволява импортиране на конкретни функции и константи от пространства от имена, а не само класове.

```php
// app/Services/StringManager.php
namespace App\Services;

use function SomeLib\stringHelper;
use const SomeLib\API_VERSION;

class StringManager
{
    public function getVersion(): string
    {
        return stringHelper(API_VERSION);
    }
}
```

* **Защо това е важно**: Това позволява да се избегне замърсяването на глобалното пространство от имена и нагледно да се декларират зависимостите от външни библиотеки в началото на файла.

<a id="const-expr"></a>
## Константни изрази

В декларациите на константи на класове, стойности на свойства по подразбиране и параметри вече могат да се използват скаларни изрази (математически формули, конкатенация).

```php
// app/Config/Limits.php
class Limits
{
    public const ONE_MB = 1024 * 1024;
    public const MAX_UPLOAD = self::ONE_MB * 50; // 50MB
    public static $debugMode = (self::MAX_UPLOAD > 10000);
}
```

<a id="hash-equals"></a>
## Безопасно сравнение на низове (`hash_equals`)

Сравнява два низа за еднакво време, независимо от това колко съвпадат техните символи.

```php
// app/Services/Security.php
$signature = $_GET['signature'];
$expected = hash_hmac('sha256', $data, $key);

if (hash_equals($expected, $signature)) {
    // Подписът е верен
}
```

* **Защо это важно**: Предотвратява атаки по време (timing attacks) при валидиране на потребителски токени, пароли или HMAC подписи.

<a id="common-mistakes"></a>
## ⚠️ Чести грешки

### 1. Приоритет на унарните оператори и степенуването
Смесването на отрицание `-` или други унарни оператори с `**` без скоби може да доведе до грешки при компилация или грешни изчисления.

```php
// app/Demo/MathErrors.php
// ❌ Грешка при компилация! Операторът за степенуване има по-висок приоритет
$result = -2 ** 2; 

// ✅ Правилен подход
$result = (-2) ** 2; // 4
```

### 2. Използване на остарялата променлива `$HTTP_RAW_POST_DATA`
Преди PHP 5.6 за необработени POST данни се използваше `$HTTP_RAW_POST_DATA`. В PHP 5.6 тя е обявена за остаряла.

```php
// app/Http/Webhook.php
// ❌ Остаряло в PHP 5.6, предизвиква E_DEPRECATED
$data = $HTTP_RAW_POST_DATA;

// ✅ Правилен подход
$data = file_get_contents('php://input');
```

### 3. Обработка на грешки в json_decode()
Методът `json_decode()` стана по-строг към некоректни литерали (например `TRUE`, `FALSE`, `NULL` в горен регистър), хвърляйки синтактични грешки там, където преди връщаше `null`.

## Практически рецепти

### Избягване на `call_user_func_array`

```php
// app/Demo/UnpackDemo.php
class Invoker
{
    public function execute(callable $callback, array $params)
    {
        // Очакване: Заменяме бавния call_user_func_array с разопаковане
        // Реалност:
        // В PHP 5.5: call_user_func_array($callback, $params);
        // В PHP 5.6:
        return $callback(...$params);
    }
}
```

<a id="backward-incompatible"></a>
## Обратна несъвместимост

1. **Строги проверки на SSL/TLS по подразбиране**: Проверката на хоста и веригата от сертификати вече е включена по подразбиране. Заявки към сървъри със самоподписани сертификати ще се отхвърлят, освен ако не се настрои контекст на потока ръчно.
2. **Приоритет на `**`**: Промяната на асоциативността на оператора за степенуване може да повлияе на математическите изчисления при пренос на код.
3. **Строгост на `json_decode()`**: Използването на главни букви в JSON литералите вече предизвиква синтактични грешки.
4. **Презаписване на ключове в масиви**: Декларации на статични масиви с повтарящи се ключове вече ги презаписват строго в реда на срещане.

4. **Вярно или грешно?** Функцията `hash_equals()` е безопасна срещу атаки по време, защото сравнява низове за променливо време.
