# PHP 8.2: Основни нововъведения

PHP 8.2 нататък наглася езика към по-явни модели: **readonly класове**, по-богата **типова система** (вкл. **DNF**), и **`#[SensitiveParameter]`**, за да не изтичат пароли в backtrace. Има и промени с реално въздействие в prod: **ASCII case** без locale за базовите string функции, различно поведение на `str_split('')`, `glob()` при `open_basedir`, плюс **deprecation на динамични свойства** без изрично позволение.

<a id="sensitive-parameter"></a>
## #[SensitiveParameter] и трасиращи изходи

`#[\SensitiveParameter]` маркира параметри за редактиране в stack traces — по-малко случайни токени и пароли в логове.

```php
function connect(#[\SensitiveParameter] string $password): void
{
    throw new RuntimeException('fail');
}
```

<a id="readonly-classes"></a>
## Readonly класове

`readonly class` прави всички instance properties readonly и ги инициализира през конструктора.

```php
readonly class Point
{
    public function __construct(
        public int $x,
        public int $y,
    ) {}
}
```

<a id="standalone-types-dnf"></a>
## Самостоятелни типове (`null`, `false`, `true`) и DNF

`null`, `false` и `true` могат да стоят като самостоятелни типове. **DNF** комбинира union и intersection в нормализиран вид.

```php
function accepts((Countable&Traversable)|null $c): void {}
```

Консолидира и разширява API за RNG — по-ясни избори и по-добра тестваемост.

<a id="extension-updates"></a>
## Разширения: cURL, PCRE

- **cURL**: `CURLINFO_EFFECTIVE_METHOD`, `curl_upkeep()`, нови константи според libcurl.
- **PCRE**: модификатор **`n`** — обикновените `()` групи не хващат, само именовани.

<a id="backward-incompatible"></a>
## Обратно несъвместими промени (миграция)

### Дата и час

- Tentative `static` при factory методите на DateTime / DateTimeImmutable.
- По-строги относителни формати за `number`.

### Стандартна библиотека

- Основните string функции за case — **ASCII**, не locale; за локал — **mbstring**.
- `str_split('')` → празен масив.
- `glob` / `GlobIterator` при `open_basedir` — различно `[]`/`false` и предупреждения.
- `FilesystemIterator` — `SKIP_DOTS` вече не е принудително подразбиране през стари флагове по подразбиране.
- `var_export` — пълно квалифицирани имена на класове.

### ODBC / PDO_ODBC

Екраниране на user/pass при допълване на connection string.

**Бележка:** при липса на timezone настройки `date_default_timezone_get()` може да върне **UTC** — валидирайте.

<a id="deprecations"></a>
## Deprecated

- Динамични свойства без `#[\AllowDynamicProperties]` или декларация.
- Относителни callables в определени форми.
- `"${var}"` интерполация.
- `utf8_encode` / `utf8_decode`.

<a id="extensions-notes"></a>
## Разширения и runtime

OpenSSL AEAD chacha20-poly1305, OCI8 LOB prefetch tuning, DBA LMDB флагове.

## Обобщение

PHP 8.2 награждава екипите с явни модели и по-малко „магия“: readonly класове, по-точни типове, по-малко изтичане на секрети. Отделете време за **низове/locale**, **open_basedir** и **timezone** след ъпгрейд.
