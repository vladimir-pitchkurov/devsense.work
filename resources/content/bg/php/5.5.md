# PHP 5.5: Основни нововъведения

**PHP 5.5** популяризира **генератори** с `yield`, добавя **`finally`**, въвежда API **`password_hash` / `password_verify`**, **`array_column()`** и **`ClassName::class`**. Често се доставя **Zend OPcache** — променя се производителността и начинът, по който новият код се вижда след деплой.

[migration55](https://www.php.net/manual/en/migration55.php).

<a id="generators"></a>
## Генератори

```php
function lines($path)
{
    $fh = fopen($path, 'rb');
    try {
        while (($line = fgets($fh)) !== false) {
            yield rtrim($line, "\r\n");
        }
    } finally {
        fclose($fh);
    }
}
```

<a id="finally"></a>
## `finally`

Изпълнява се винаги след try/catch, дори при `return` или изключение.

<a id="password-api"></a>
## Пароли

```php
$hash = password_hash($plain, PASSWORD_DEFAULT);
if (password_verify($plain, $hash) && password_needs_rehash($hash, PASSWORD_DEFAULT)) {
    $hash = password_hash($plain, PASSWORD_DEFAULT);
}
```

<a id="helpers"></a>
## Помощници

**`array_column()`** извлича колона от масив от редове; **`::class`** дава низ с пълното име на класа.

<a id="opcache"></a>
## OPcache

След промяна на файлове може да е нужен рестарт на PHP-FPM или изчистване на кеша.

<a id="practical-recipes"></a>
## Рецепти

### Итератор вместо масив

При огромни логове или дъмпове избягвайте **`file()`**, което вдига целия файл в RAM. Ползвайте **генератор** с **`yield`**, за да четете ред по ред и да държите паметта предвидима.

### Миграция на пароли

При вход извиквайте **`password_verify`** срещу стари хешове. Ако паролата е валидна и **`password_needs_rehash`** върне true, веднага презапишете хеша с **`password_hash(..., PASSWORD_DEFAULT)`**, за да изнесете акаунтите към актуални настройки без масов reset.

<a id="backward-incompatible"></a>
## Обратна несъвместимост

Важни точки (пълен списък: [migration55 incompatible](https://www.php.net/manual/en/migration55.incompatible.php)):

- **`foreach`** с **вътрешни указатели** в масива и **обхождане по референция** — променени са крайни случаи; направете регресия върху код, който мутира масива по време на итерация.
- **`list()`** в **`foreach`** — по-строга семантика за вложени списъци; проверете шаблони, които разопаковат вложени масиви.
- **`GD`**, **`intl`**, **`openssl`** и други разширения — сигнатури и режими на грешки; ако ги обвивате, вижте бележките към отделните функции.
- **`::class`** в контекст на ключовата дума **`class`** — в много стар код избягвайте двусмислици с имена и константи.

<a id="deprecations"></a>
## Deprecated

- Разширение **`mysql`** — насока само към **mysqli** или **PDO**.
- Модификатор **`/e`** в **`preg_replace()``** — **опасен**; заменете с **`preg_replace_callback()`**.

Подробности: [migration55 deprecated](https://www.php.net/manual/en/migration55.deprecated.php).

<a id="other-changes"></a>
## Друго

- Разширено **`empty()`** за изрази — променено поведение; пуснете тестове за форми и шаблони като `empty($x->y)`.
- **Цената на хеширане** се актуализира с версиите на PHP — планирайте **rehash при успешен login**.

---

## Обобщение

PHP 5.5 е стъпката **„контрол на паметта + нормални пароли“** преди синтактичните удобства в 5.6: усвоете **генератори** и **`password_*`**, приключете с **`mysql`**, след което **вариадиката и `**` в 5.6** идват естествено.
