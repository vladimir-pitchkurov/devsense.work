# Инструкция по деплою проекта DevSense в продакшн

Этот документ описывает шаги по первому развертыванию и обновлению проекта DevSense в продакшн-окружении с целью максимального сохранения и улучшения SEO/GEO-показателей.

---

## 1. Конфигурация окружения (.env)

Перед запуском деплоя убедитесь, что в файле `.env` на продакшн-сервере установлены следующие параметры:

```env
# Базовые настройки приложения
APP_ENV=production
APP_DEBUG=false
APP_URL=https://devsense.work # Без слеша на конце! На основе APP_URL формируются все канонические ссылки и hreflang.

# Настройки SEO и индексации
SEO_ALLOW_INDEXING=true # Разрешает индексацию (иначе robots.txt запретит доступ всем краулерам)

# Настройки IndexNow для мгновенной отправки URL поисковикам и AI-краулерам
SEO_INDEXNOW_ENABLED=true
SEO_INDEXNOW_KEY=8d2f7850a1e34bcf9db7519bb8d2ef5a # Ваш уникальный 32-значный ключ
```

---

## 2. Автоматизированный деплой

В корне проекта находятся скрипты деплоя:
* `deploy.sh` — для деплоя ветки `prod` в продакшн-окружение.
* `deploy-dev.sh` — для деплоя ветки `development` в тестовое окружение.

Эти скрипты автоматически выполняют следующие действия:
1. Переводят приложение в режим обслуживания (`php artisan down`).
2. Стягивают свежие изменения из репозитория Git.
3. Устанавливают зависимости Composer (`composer install --no-dev`).
4. Очищают и оптимизируют кэш Laravel.
5. Накатывают миграции базы данных (`php artisan migrate --force`).
6. **[Автоматизировано]** Импортируют все новые и измененные Markdown-статьи из папки `resources/content` в базу данных (`php artisan app:migrate-articles-to-database`).
7. **[Автоматизировано]** Генерируют статическую карту сайта в файл `public/sitemap.xml` (`php artisan sitemap:write`), чтобы Nginx отдавал её напрямую без обращения к PHP.
8. **[Автоматизировано]** Делают пинг поисковых систем через IndexNow (`php artisan seo:ping-indexnow`) для новых или измененных страниц.
9. Перезапускают PHP-FPM для сброса OPcache.
10. Выводят приложение из режима обслуживания (`php artisan up`).

### Запуск деплоя:
```bash
./deploy.sh
```

## 3. Проверка готовности SEO & GEO

После завершения деплоя выполните следующие проверки:

### 1. Доступность Robots.txt и Sitemap
Перейдите по адресу `https://devsense.work/robots.txt`. Вы должны увидеть:
```txt
User-agent: *
Allow: /

Sitemap: https://devsense.work/sitemap.xml
```
Убедитесь, что сам файл `https://devsense.work/sitemap.xml` открывается и содержит XML-структуру со ссылками на все языковые версии страниц.

### 2. Валидация ключа IndexNow
Поисковики должны иметь возможность верифицировать ваш ключ IndexNow. Перейдите по адресу:
`https://devsense.work/8d2f7850a1e34bcf9db7519bb8d2ef5a.txt` (или ваш ключ из `.env`).
Сервер должен вернуть чистый текстовый ключ со статусом ответа `200 OK`.

### 3. Ручной пинг всех страниц (для первого запуска)
Так как автоматический пинг при деплое отправляет только изменившиеся с последнего запуска файлы, при самом первом запуске проекта на проде рекомендуется принудительно скормить поисковикам все существующие URL (110+ адресов):
```bash
php artisan seo:ping-indexnow --force
```

### 4. Настройка Nginx-редиректов (Склеивание дублей)
Убедитесь, что Nginx настроен на:
* Редирект с `http://` на `https://`.
* Редирект с `www.devsense.work` на `devsense.work` (без `www`).
Это предотвратит появление дублирующего контента в индексах поисковых систем.

### 5. Регистрация в Google Search Console и Bing Webmaster Tools
1. Зарегистрируйте домен `devsense.work` в панелях вебмастеров.
2. Добавьте ссылку на Sitemap (`https://devsense.work/sitemap.xml`) в Google Search Console в разделе "Файлы Sitemap".
3. Добавьте её же в Bing Webmaster Tools (Bing также начнет импортировать данные о посещениях через IndexNow).
