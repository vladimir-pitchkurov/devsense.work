Блок 1. Архитектура и System Design (Высокий приоритет)
Здесь CTO будет проверять твой переход от мышления "один сервер - одна БД" к распределенным системам.

1.1. Агрегация данных и High-Load:

Как собирать миллионы ивентов (ставки, спины, клики из Ad-tech) не положив основную базу (паттерны буферизации, использование Redis Streams или брокеров сообщений вроде RabbitMQ/Kafka).

Разделение OLTP (транзакционная база) и OLAP (база для аналитики/панели).

1.2. Интеграции и отказоустойчивость:

Работа с API провайдеров игр и платежек. Что делать, если внешний сервис упал/завис (Circuit Breaker, Retry patterns).

Идемпотентность запросов (как избежать двойного списания денег при лагах сети).

1.3. Конкурентность и гонки данных (Race Conditions):

Классическая задача iGaming: два одновременных списания баланса. Пессимистичные (Pessimistic Locking) и оптимистичные (Optimistic Locking) блокировки в БД.

Блок 2. Базы данных: PostgreSQL и Redis (Критический приоритет для панели)
Панель статистики = сложные запросы. Тут нужен уровень Senior.

2.1. PostgreSQL на стероидах:

Продвинутое индексирование (B-tree, Hash, когда использовать составные индексы).

Партицирование таблиц (Partitioning) — мастхэв для логов и статистики по датам.

Материализованные представления (Materialized Views) для быстрых дашбордов.

Типы данных JSONB для неструктурированных логов провайдеров.

2.2. Redis (не только как кэш):

Использование Redis для Rate Limiting.

Очереди на Redis (в контексте Laravel Horizon).

Pub/Sub для WebSockets (обновление статистики в панели в реальном времени).

Sorted Sets для лидербордов (частая фича в казино).

Блок 3. Backend: PHP & Laravel (Core Expertise)
Ожидается глубокое понимание фреймворка за пределами CRUD.

3.1. Архитектура внутри Laravel:

Борьба с "толстыми" контроллерами и моделями: Action classes, Service layer, DTO (Data Transfer Objects) для общения между модулями.

Оптимизация Eloquent: проблема N+1, chunk() vs cursor() для экспорта больших отчетов, когда нужно использовать Query Builder или raw SQL вместо Eloquent.

3.2. Фоновые задачи (Queues & Jobs):

Настройка очередей, обработка failed_jobs, таймауты, лимиты памяти при тяжелых импортах/экспортах статистики.

3.3. Тестирование и Legacy:

Как безопасно рефакторить старый код без тестов (стратегия удушения - Strangler Fig pattern).

Блок 4. Frontend: Vue vs React (Твой гэп)
У тебя сильный Vue, нужен React. Будем строить мосты.

4.1. Концептуальный маппинг:

Vue Composition API (setup) vs React Hooks (useState, useEffect).

Жизненный цикл компонентов: как это работает под капотом React.

4.2. Управление состоянием:

Vuex/Pinia vs Redux/Zustand. Контекст (useContext).

4.3. Оптимизация рендера:

Почему React рендерит больше, чем Vue. Как работают useMemo, useCallback, React.memo (очень важно для таблиц со статистикой, чтобы они не лагали).

Блок 5. DevOps, CI/CD и Инфраструктура
5.1. Docker и контейнеризация: Best practices написания Dockerfile для PHP/Node.js.

5.2. CI/CD Pipeline: Этапы пайплайна (линтеры, тесты, сборка ассетов, деплой).

5.3. Zero-downtime deployment: Как выкатывать обновления панели без отключения пользователей.

Блок 6. Поведенческие вопросы (Soft Skills / CTO Fit)
Рассказ о самом сложном баге (ожидается история про дебаг на проде, утечки памяти или race condition).
