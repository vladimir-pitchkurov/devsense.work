# План развития проекта (Roadmap)

## Фаза 1: MVP (Персональный справочник) — [x] Выполнено
- [x] Базовая структура UI (Tailwind CSS / Blade).
- [x] Раздел "Гайды по PHP":
    - [x] PHP 8.0 (Named Arguments, Match Expression, Nullsafe Operator).
    - [x] PHP 8.1 - 8.5 (постепенное наполнение).
- [x] Раздел "Инструменты разработчика":
    - [x] Статья: Эволюция локальной среды (от Valet к Laravel Sail).

## Фаза 2: Динамический контент — [x] Выполнено
- [x] Дополнительные разделы (Микросервисы, Архитектура, Инструменты, Вакансии).
- [x] Перенос статей из хардкода (файловой структуры ресурсов) в базу данных PostgreSQL.
- [x] Механизм синхронизации через консольную команду `app:migrate-articles-to-database`.
- [x] Админ-панель для авторов и администраторов с редактором Markdown.

## Фаза 3: Платформа для авторов — [x] Выполнено
- [x] Аутентификация (Регистрация `/register` с автоматическим присвоением роли `author` и Вход `/login`).
- [x] Ролевая модель (Супер-админ, Автор, Читатель).
- [x] Ограничение доступа в админ-панели (кабинете автора): не-администраторы видят и могут редактировать/удалять только свои собственные статьи.
- [x] Возможность гибкого управления публичностью профиля автора через настройки (`is_public`).

## Фаза 4: Улучшение UI/UX и Модерация — [x] Выполнено
- [x] Исправление съехавшей верстки пагинации в списках статей.
- [x] Адаптивный логотип: отображение большого логотипа для десктопной версии и компактной иконки для мобильной.
- [x] Полноценный кликабельный переход на статью по всей карточке (вместо клика только на стрелку).
- [x] Добавление ссылок в публичный интерфейс (UI) для перехода на страницу входа/регистрации в кабинет автора.
- [x] Интеграция настроек видимости страницы автора: исключение непубличных авторов из списков, поиска и запрет гостевого доступа.
- [x] Система модерации черновиков (Drafts/Pending) для статей и профилей авторов.
- [x] Механизм жалоб пользователей на контент и страницы условий использования / конфиденциальности (Terms & Conditions, Privacy Policy).

## Фаза 5: Облачное хранилище и Изоляция сред — [x] Выполнено
- [x] Интеграция DigitalOcean Spaces (S3-совместимое хранилище) для загрузки изображений в медиа-библиотеке и профилях.
- [x] Разделение папок загрузок по префиксам сред (`uploads/dev/` против `uploads/prod/`).
- [x] Блокировка индексации (robots `noindex, nofollow`, скрытие Sitemap) на не-продакшн средах (`APP_ENV !== 'production'`).
- [x] Отключение скриптов аналитики (GTM / GA) и уведомлений IndexNow на dev-окружениях.

## Фаза 6: Расширение языков и перевод статей — [ ] Планируется (Немедленный приоритет)
- [ ] Добавить поддержку 4 новых локалей: немецкий (`de`), французский (`fr`), испанский (`es`) и итальянский (`it`) в `SetLocale::SUPPORTED_LOCALES` и API-сервисы.
- [ ] Интегрировать механизм резервных переводов (translation fallback) для корректной обработки новых локалей с переключением на английский/первый доступный перевод.
- [ ] Выполнить перевод всех существующих технических руководств и статей на немецкий, французский, испанский и итальянский языки перед началом реализации следующих крупных фич.
- [ ] Адаптировать выпадающий список выбора языка (UI) для поддержки всех 8 активных локалей.

## Фаза 7: Интерактивные квизы и посев данных — [ ] Планируется (Высокий приоритет)
- [ ] Проектирование схемы БД для квизов: таблицы для квизов, вопросов, вариантов ответов, правильных ответов и пояснений.
- [ ] Мультиязычность контента квизов: перевод вопросов, вариантов ответов и пояснений на все 8 поддерживаемых языков.
- [ ] Создание консольной команды `app:seed-quizzes` для посева и обновления квизов из структурированных файлов (YAML/JSON).
- [ ] Разработка админ-интерфейса (доступного только супер-администратору) для создания, импорта, редактирования и управления квизами и их переводами.
- [ ] Публичный интерфейс для прохождения квизов, проверки ответов в реальном времени и просмотра объяснений правильных ответов.

## Фаза 8: Процесс модерации и резервные переводы (Обновление валидации и локализации статей) — [x] Выполнено
- [x] Обход HTML5 валидации в скрытых вкладках (удален блокирующий атрибут `required`).
- [x] Ослабленные правила валидации переводов (требуется как минимум одна заполненная локаль, запрещены частичные переводы).
- [x] Механизм резервных переводов из базы данных (локаль -> `en` -> первый доступный перевод).
- [x] Возможность предварительного просмотра черновиков авторами для неутвержденных или неопубликованных статей (предотвращение ошибки 404).
- [x] Визуальные индикаторы статуса в реальном времени (`In Review` / На модерации, `Update in Review` / Обновление на модерации) в списке статей.
- [x] Оптимизация запросов (eager-loading) переводов в админ-панели во избежание проблемы N+1 запросов.

## Фаза 9: Универсальные профили и портфолио пользователей (Основа для хайринга) — [ ] Планируется (Средний приоритет)
- [ ] Распространить публичные страницы профилей на всех зарегистрированных пользователей (читателей), а не только на авторов.
- [ ] Добавить настраиваемые разделы в профиль пользователя:
    - [ ] Теги навыков (PHP, Laravel, Vue, DevOps и т. д.).
    - [ ] Профессиональный опыт (история работы, роли).
    - [ ] Образование и сертификаты.
    - [ ] Ссылки на портфолио (GitHub, LinkedIn, личный сайт, выполненные проекты).
- [ ] Реализовать переключатель приватности (`is_public`), позволяющий обычным пользователям открывать или скрывать свое портфолио разработчика.
- [ ] Спроектировать архитектуру профилей с заделом под будущую интеграцию с платформой найма/рекрутинга (поиск по навыкам, опыту, фильтрация кандидатов).

## Фаза 11: Целостность и верификация электронной почты — [ ] Планируется (Низкий/Средний приоритет)
- [ ] Внедрение надежной верификации электронной почты с помощью сервиса Resend.
- [ ] Строгая валидация при регистрации пользователей:
    - [ ] Выполнение проверки записей MX для доменов для подтверждения существования почтового сервера.
    - [ ] Создание черного списка (blocklist) для известных провайдеров временной/одноразовой почты.
- [ ] Защищенный процесс активации аккаунтов:
    - [ ] Отправка подписанных ссылок (signed links) для активации с коротким временем жизни.
    - [ ] Автоматическая блокировка/удаление учетных записей, не прошедших активацию в течение заданного срока.
