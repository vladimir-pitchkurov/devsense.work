# План розвитку проєкту (Roadmap)

## Фаза 1: MVP (Персональний довідник)
- [ ] Базова структура UI (Tailwind CSS / Blade).
- [ ] Розділ "Гайди з PHP":
    - [ ] PHP 8.0 (Named Arguments, Match Expression, Nullsafe Operator).
    - [ ] PHP 8.1 - 8.5 (поступове наповнення).
- [ ] Розділ "Інструменти розробника":
    - [ ] Стаття: Еволюція локального середовища (від Valet до Laravel Sail).

## Фаза 2: Динамічний контент
- [ ] Розділ "JavaScript".
- [ ] Перенесення статей з хардкоду (Blade) у базу даних.
- [ ] Адмін-панель для зручного написання статей (Markdown Editor).

## Фаза 3: Платформа для авторів
- [ ] Аутентифікація (Laravel Breeze / Jetstream).
- [ ] Рольова модель (Адмін, Автор, Читач).
- [ ] Можливість публікації статей іншими користувачами.

## Фаза 4: Ком'юніті
- [ ] Форум для обговорення технологій.
- [ ] Реал-тайм чат (Laravel Reverb / WebSockets).
