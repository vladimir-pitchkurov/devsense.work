# Чернетка статті: Еволюція локальної розробки

**Тема:** Мій шлях налаштування локального середовища для PHP і чому Laravel Sail — це топ.

**План статті:**
1. **Вступ:** Біль локального налаштування.
2. **Епоха macOS та Valet:** Швидко, нативно, але прив'язує до маку та забруднює хост-систему.
3. **Епоха серверів:** Встановлення LAMP/LEMP (Apache -> Nginx). Різниця між локальним середовищем та продакшеном.
4. **Епоха Docker "своїми руками":** Написання складних docker-compose, налаштування мереж, зв'язка Nginx + Traefik. Гнучко, але складно підтримувати.
5. **Одкровення Laravel Sail:**
    - Що це таке (легковагова CLI-обгортка над Docker).
    - Як я запустив проєкт у 2026 році (інтеграція WSL2, laravel.build).
    - Магія "з коробки": PHP, MySQL, Redis запускаються однією командою.
    - Міграції та права доступу без головного болю.
6. **Висновок:** Чому для старту проєктів зараз я обираю Sail.
